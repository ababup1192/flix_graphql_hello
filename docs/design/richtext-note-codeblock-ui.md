# note のコードブロックの UI（実物の言語化）

2026-09-11 に note の編集画面（ダーク）のスクリーンショット 5 枚から書き起こした。
richtext-note-style.md §6.11 の細部で、実装と見比べる時の正。推測は明記する。

## 1. 入れた直後（空のコードブロック）

| 項目 | note |
|---|---|
| 本体 | 濃いグレー（#333 程度）の箱。左右は本文の幅いっぱい、高さは 3 行分程度の最低の高さ |
| 言語の欄 | **箱の下、右寄せ**に小さな帯（本体より少し明るい面）。中に入力欄（枠なし）が 1 つ |
| placeholder | 「コーディング言語」 |
| カーソルを入れた時 | 入力欄に水色の枠（#7fb3d5 程度）、角丸 4px |

## 2. フォーカスが外れている時

| 項目 | note |
|---|---|
| 言語の欄 | **帯だけが残り、入力欄も placeholder も見えない**（帯は本体と同じ幅の右端に、薄く残る） |
| 本体 | 枠の強調なし |

## 3. 打っている時（候補の一覧）

| 項目 | note |
|---|---|
| 一覧の位置 | 入力欄の**下**。入力欄の左端に揃える |
| 一覧の見た目 | 明るめのグレーの面（#5a6066 程度）、角丸 6px、影。高さは 5 行程度で**縦にスクロール**（スクロールバーが見える）、横のスクロールバーも出ている |
| 行 | 左に言語のアイコン（色付き。C は青、C# は紫、Cassandra は黄、CSS は青、Cython は緑など Devicon 風）、右に言語名（小文字の素の名前: `c` `c#` `c++` `cassandra` `ceylon` `crystal` `csharp` `css` `cypher` `cython`） |
| 絞り込み | 打った文字で前方一致（`c` で上の並び）。**別名も別の行として出る**（`c#` と `csharp` の両方） |
| 選択中の行 | 薄い明るい背景 |
| 決め方 | 押す。キーの上下も効く（推測） |

## 4. 決めた後

| 項目 | note |
|---|---|
| 言語の欄 | 帯の中に言語名（`C++`。**表示は整った名前**で、候補の一覧の素の名前とは違う） |
| 本体 | ハイライトが効く（`void` が緑、`main` が紫、`int` が緑） |
| 行 | 行間は広め、等幅 |

## 5. 今の実装との差

| 差 | 今 | note |
|---|---|---|
| 言語の欄の位置 | ブロックの**上**の帯 | ブロックの**下**、右寄せ |
| 選び方 | `select`（OS の一覧） | 打って絞り込む入力欄 + 自前の候補の一覧 |
| アイコン | 無し | 言語ごとの色付きアイコン |
| 見えない時 | 帯が常に見える | フォーカスが無いと帯だけ（文字は出ない） |
| 表示名 | 素の名前 | 整った名前（`C++`）。候補は素の名前（`c++`） |
| ファイル名 | 上の帯に入力欄 | note には無し |

## 6. こちらの決め

- **アイコンは外部の画像を使わない**。言語ごとの色の四角に頭文字（`Ui.initialMark` と同じ形、8 色を言語に割り当てる）。Devicon を CDN から読むと依存が増え、オフラインで崩れる
- **ファイル名の欄は残す**（note に無いが、技術文書では要る）。置き場は言語の帯の**左端**。言語は右端
- 表示名と素の名前の対は `code-languages.ts`（今は素の名前だけ）に表として持つ
- 別名（`c#` / `csharp`、`js` / `javascript`）は**候補には両方出し、決めた後は正の名前に寄せる**。doc に入るのは正の名前だけ（往復が揺れない）


## 7. 強調行（2026-09-11 に追加。note に無いこちらの決め）

CMS 側は `codeBlock.attrs.highlightLines`（`1,3-5` の形）を最初から持っていて、検査・HTML の
`data-highlight-lines`・Markdown の往復まで揃っている。**画面に入力の口だけが無かった。**

最初は帯に「強調行（例: 1,3-5）」の欄を置いたが、**人に `1,3-5` を書かせるのが不自然**だった。
代わりに行番号を出し、押して選ぶ形にする。

| 項目 | 決め |
|---|---|
| 行番号 | コードブロックの左に常に出す（強調行が無くても）。押せる |
| 1 行を選ぶ | 行番号を押す。もう一度押すと解除 |
| 範囲を選ぶ | Shift を押しながら押すと、前に選んだ行からそこまで |
| 強調の見た目 | その行の地を薄く変える（左に印を足してもよい） |
| 保存の形 | `attrs.highlightLines` は今のまま `1,3-5`。CMS と Markdown は変えない |
| 帯の欄 | 置かない（行番号で足りる） |
| 公開側 | HTML は今のまま `<pre data-highlight-lines><code>`。行を要素で包まない。
行番号と強調はサイト側の CSS と JS が決める（作例に 1 例を載せる） |

他社: Zenn と Docusaurus は記法で書かせる。Notion のコードブロックと GitHub の差分は押して選ぶ。
読み手にとっても行番号があると本文で「3 行目を見て」と書けるので、両方に効く。
