画像とキャプション

画像の下に説明を置き、必要なら出典を付ける。出典はテキストだけでも、リンク付きでもよい。

引用と出典

出典は blockquote の外の figcaption に置く。HTML の仕様が求める形で、CSS の当て方も画像と揃う。

出典の無い引用は今まで通り素の blockquote のまま。見た目は同じになる。

外部リンクのカード

URL を単独の行に貼るとカードになる。カードは a 要素 1 つで、中身は span と img だけ。JavaScript も iframe も要らない。
