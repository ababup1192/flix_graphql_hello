# note のリンクカードの UI（実物の言語化）

2026-09-11 に note の編集画面（ダークテーマ）のスクリーンショット 3 枚と、ユーザーの目視（ローディング）から書き起こした。
richtext-note-style.md §3.3 / §6.6 の細部で、実装と見比べる時の正。推測は明記する。

## 1. 「+」→ 埋め込みで URL を入れる時

| 項目 | note |
|---|---|
| 出る物 | 「+」（丸に + の薄い線）の右に、帯が「URL の入力欄 + 適用 + ×」の形で出る。画像のリンク入力と同じ部品 |
| 入力欄 | 青い focus の枠、白い文字で URL |
| 決定 | 適用か Enter |

## 2. 取りに行っている間（ユーザーの目視。一瞬）

| 項目 | note |
|---|---|
| 出る物 | **カードと同じ大きさ・形の白い箱**。中に「…」のアニメーション（点が順に動く） |
| 意味 | OGP を**貼った瞬間に取りに行く**。保存を待たない |

## 3. カードになった時

| 項目 | note |
|---|---|
| 形 | 横長の箱。高さ 200px 程度、角丸 4px、細い枠線（#4a5056 程度） |
| 左 | 上から **タイトル（太字、白、18px 程度）/ 説明（灰色 #9a9fa5、2 行で「…」で切る）/ ドメイン（白、小さめ、`google.com`）**。左の余白 32px、上下は中央寄せ |
| 右 | **サムネイル。幅は箱の 30% 程度、高さは箱いっぱい**。OGP 画像が無い時は薄い灰色（#f5f6f6）の面に灰色の画像アイコン |
| 押した時 | 編集画面ではどこも押せない（推測） |

## 4. カードを選んだ時

| 項目 | note |
|---|---|
| 枠 | 画像と同じ水色 4px の実線 |
| 帯 | カードの上、中央に **削除（ゴミ箱）だけ** の帯 |
| 消した後 | 空の段落に戻る（推測。richtext-note-style §6.6 では「素の URL の段落に戻す」と決めていたが、note は空に戻す可能性が高い。こちらは URL の段落に戻す方を残す。理由: 貼り直しが要らない） |

## 5. 取れなかった時（未確認・推測）

- note は URL だけのリンクの行になるか、カードに URL だけ出す。こちらは §3.3 の決めどおり、**カードの枠の中に URL と理由**（「相手のサイトが自動取得を拒んでいます」「404」「OGP がありません」）を出す

## 6. 設計の変更（richtext-note-style §3.3 から）

- **取るタイミング**: 「保存時に仕事で取る」→ **編集画面が貼った瞬間に管理 API に頼み、その場で取る**。取れた物は表（url → title, description, imageUrl, siteName, fetchedAt, error）に残し、公開の `toHtml` は表から `cards` を組む（ここは変わらない）
- **仕事（BackgroundJobs）の役割**: 初回取得ではなく、**古くなった行の取り直し**（fetchedAt が 7 日より前）と、失敗した行の再試行に絞る
- **管理 API**: `mutation fetchLinkCard(url)` を 1 つ足す。中で `OutboundHttp.runWith` で HTML の先頭（最大 512KB、5 秒）を取り、OGP（og:title / og:description / og:image / og:site_name、無ければ `<title>`）を読み、表に upsert して返す。同じ URL が表にあり 7 日以内なら取りに行かず返す
- **OGP 画像**: 相手の URL をそのまま返す（第 1 段）。自前の置き先に写すのは後（§3.3 の理由は変わらない。写す仕事は「取り直し」と同じ仕事に足す）
- **doc**: 変えない。`linkCard.attrs.url` のみ。OGP は doc に持たない

## 7. こちらで決める物

- 編集画面のカードの見た目は 3 と同じ。ライトテーマでは箱の背景を紙色、右の面は薄い灰色
- ローディングは 2 と同じ「…」。3 秒を超えたら「取得中…」を薄く出す（推測ではなくこちらの決め）
- カードは選べるが中は編集できない。URL を直すには消して貼り直す（note と同じ）
