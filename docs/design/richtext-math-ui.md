# 数式の UI（他社の形と、こちらの決め）

2026-09-11。note には数式が無いので、Notion と Craft と Zenn を下敷きにする。
`richtext-note-style.md` §6.11 の細部で、実装と見比べる時の正。他社の形は一般知識からの記述で、実物の確認はしていない（推測）。

## 1. 今の不具合（ユーザーの指摘）

| # | 何が起きるか | 原因 |
|---|---|---|
| 1 | TeX の欄を掴んで伸ばすと「+」の位置がずれ、欄が箱からはみ出す | `.tt-mathblock-src` が `resize: vertical`。伸ばした高さは node view の外の layout に伝わらない |
| 2 | 消し方が分からない | 削除の口が無い。中の欄に焦点がある間は Backspace が TeX を消すだけ |
| 3 | 組版された数式の辺りを押すとカーソルが変な所に当たる | 上半分（`.tt-mathblock-out`）に押した時の動きが無く、ProseMirror が近い位置を推測する |
| 4 | 押す場所で「編集」と「選択」が入れ替わり、当たり判定がシビア | 組版の面だけが編集で、余白と枠は ProseMirror の選択だった（2026-09-11 に箱全部を編集にし、消す口はホバーの削除へ移した） |
| 5 | TeX を打っている間、上下の矢印で前後の行へ出られない | node view の `stopEvent` が鍵を全部食べ、`BlockEdges` に届かない（2026-09-11 に 1 行目の ↑ と最終行の ↓ で `leaveBlock` を呼ぶようにした） |

## 2. 他社の形（推測）

| | Notion | Craft | Zenn |
|---|---|---|---|
| 普段 | 組版された数式だけ | 同じ | 同じ（プレビュー） |
| 触ると | 数式を押すと TeX の小さな面が浮く | 数式の下に TeX の行が開く | Markdown なので常に TeX |
| 消す | ブロックの左の「⋮⋮」→ 削除、または空で Backspace | 同じ | 行を消す |
| 空の時 | placeholder（`E = mc^2` のような例） | 同じ | — |

共通するのは **「普段は組版だけ、触った時に TeX、選ぶと削除」** の 3 状態。

## 3. こちらの決め

| 項目 | 決め |
|---|---|
| 普段（焦点なし・選択なし） | **組版された数式だけ**。TeX の欄は見せない。空なら薄く「数式を入力」 |
| 押した時 | **箱のどこを押しても**下に TeX の欄が開き、焦点が入る（組版の上・余白・枠のどれでも同じ）。**組版はそのまま上に残る**（打つたびに描き直す）。押す口は編集に一本化し、選ぶ口は掴みだけが持つ |
| ホバーの削除（案 B） | 箱にホバーしている間だけ**右上に小さな削除**（右 6px・上 6px、28×28、角丸 4px、濃い地に白のアイコン）。押すと数式を削除して段落に戻し、カーソルを置く。読み取り専用の間は出さない。title / aria-label は「削除」。選ばずに消せる口をここに置く（押す口は編集に一本化したので、消す操作が押す場所と喧嘩しない） |
| 上下の矢印 | TeX の欄の**1 行目で ↑、最終行で ↓** で欄を閉じ、前後のブロックへ出る（無ければ疑似行を置く。`block-edges.ts` の `leaveBlock`）。途中の行では欄の中を移動する。左右の矢印は今のまま欄の中だけ（端で外へ出すと、1 行の TeX で字を戻すたびに本文へ飛ぶ） |
| 欄の高さ | **中身の行数に合わせて自動で伸びる**（`resize` は無し、最低 2 行）。掴みは出さない |
| 選んだ時（NodeSelection） | 箱に水色 4px の枠、**上に削除だけの帯**（画像・リンクカードと同じ形） |
| 消し方 | 帯の削除、または **TeX が空の状態で Backspace** で段落に戻す。中に文字がある時の Backspace は普通に 1 字消す |
| 外へ出る | Esc で欄を閉じて node を選んだ状態に。もう一度 Esc で本文へ |
| TeX が壊れている時 | 上に赤い文字で KaTeX のエラー（今と同じ） |
| 文中の数式（`$…$`） | 今のまま（カーソルが乗った時だけ TeX に戻る）。ここは触らない |

## 4. 画面の形

```
（普段）                    （押した時）                  （選んだ時）
┌──────────────┐        ┌──────────────┐        　　　🗑
│   E = mc²    │        │   E = mc²    │         ┌──────────────┐
└──────────────┘        ├──────────────┤         │   E = mc²    │
                        │ E = mc^2     │         └──────────────┘
                        └──────────────┘          （水色 4px の枠）
```

帯・枠・削除のアイコンは画像とリンクカードと同じ部品（`.tt-image-bar` / `.tt-image-tool`）を使う。
