画像とギャラリーのモック

docs/design/richtext-gallery-ui.md の決め。node は 1 つで、1 枚でも複数枚でも同じ。列数は選ばせず枚数から決める。キャプションは全体と画像ごとの 2 層。

1. 1 枚（今までどおり）

帯は note と同じ リンク / ALT / 縮小 / 配置 / 削除 の 5 つ。キャプションは画像の下の欄に直接書く。

2. 3 枚（列数は選ばせず枚数から決まる）

帯は「1 枚ずつに戻す」「削除」だけ。列数の欄は無い。縮小と配置は並べている間は出さない。

3. 画像ごとのキャプション（2 層）

画像ごとのキャプションがある画像だけ figure で包む。無い画像は素の img のまま。全体のキャプションは下に 1 つ。

4. 4 枚以上（編集画面は折り返す。横に送るかはサイトの CSS が決める）

HTML は並べ方を持たない。`data-gallery` の値は枚数。横スクロールにしたいサイトは CSS で決める。

5. 1 枚に戻った時（自動で単独の見た目に）

node は同じなので、子が 1 つになれば自動でこの見た目になる。作り直しは起きない。
