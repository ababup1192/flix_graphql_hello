# note の画像まわりの UI（実物の言語化）

2026-09-11 に note の編集画面（ダークテーマ）のスクリーンショット 5 枚から書き起こした。
richtext-note-style.md §6.4 の細部で、実装と見比べる時の正。推測の箇所は「推測」と明記する。

## 1. 画像を選んだ時

| 項目 | note |
|---|---|
| 画像の枠 | 水色（#7fb3d5 程度）の実線、太さ 4px 程度、角は丸めない。画像の外側に付く |
| 帯の位置 | 画像の上端の上、左右中央。画像とは 30px 程度の隙間 |
| 帯の見た目 | 濃いグレー（#2b2f33 程度）、角丸 6px、影は薄い。高さ 56px 程度、左右の余白 20px 程度 |
| 帯の中身 | 左から **リンク（鎖）/ ALT（英字の文字）/ 縮小（内向きの斜め矢印）/ 配置（左寄せの線のアイコン）/ 削除（ゴミ箱）** の 5 つ。全部白。ボタンの間隔は 40px 程度 |
| キャプション | 画像の下、中央に灰色（#9a9fa5 程度）の「キャプションを入力」。画像との隙間 40px 程度 |
| 出典 | 帯にも画像の下にも無い。出典はキャプションの文として書く |
| 画像の幅 | 常に本文の幅いっぱい（小さい画像も引き伸ばす）。縮小で 50%。元の大きさでは出さない（2026-09-11 に実装で確認: 元の大きさだと小さい画像で縮小が効かない） |
| 帯の active | リンク（href あり）と ALT（alt あり）は緑。縮小中の拡大アイコン、配置の今の値も緑 |

## 2. 配置を押した時

| 項目 | note |
|---|---|
| 出る物 | 5 つの帯が消え、**同じ位置に 左寄せ / 中央 / 右寄せ の 3 つのアイコンだけの帯**に入れ替わる（帯の下に面を足すのではない） |
| 今の配置 | 該当のアイコンが緑（note のアクセント #4bb08a 程度）。他は白 |
| 押せる条件 | 縮小していなくても押せる（実物は全幅の画像で出ている）。全幅の画像で左寄せ・右寄せを選んだ時の見た目は未確認（推測: 縮小した時だけ寄せが見える） |
| 閉じ方 | 1 つ選ぶと元の 5 つの帯に戻る（推測）。画像の外をクリックでも消える |

## 3. キャプションを編集している時

| 項目 | note |
|---|---|
| 画像 | 枠の強調は無い。帯も無い |
| キャプション | 画像の下、中央に白い文字。文字の大きさは本文より小さい（14px 程度） |
| 帯 | カーソルがキャプションにある間、**キャプションの真上に浮く**（画像の下端に重なる）。中身は **太字（B）/ 取り消し線 / リンク（鎖）** の 3 つだけ。見出し・引用は無い |
| 帯の見た目 | 1 と同じ濃いグレーの帯、角丸、高さ 56px 程度 |
| 押した状態 | 掛かっている物は緑（B が緑 = 太字の中にいる）。hover で上に黒い小さなツールチップ（「リンク」） |

## 4. キャプションの帯でリンクを押した時

| 項目 | note |
|---|---|
| 出る物 | 3 つの帯が **同じ位置で URL の入力に入れ替わる**。左に入力欄（placeholder `https://`、青い focus の枠）、右に「適用」ボタン（白地、黒文字、角丸）、その右に「×」 |
| 選択 | 選んでいた文字は薄い青の背景で残る |
| 決定 | 適用か Enter で掛かり、帯は 3 つに戻る。× で戻る |

## 5. リンクの掛かった文字を選んだ時

| 項目 | note |
|---|---|
| 帯 | 3 つの帯で、リンクのアイコンが緑（掛かっている印） |
| URL の表示 | 選択の**下**に小さな濃い面が出て、URL（例 `https://google.com/`）を文字で見せる。押すと開くか編集かは未確認 |

## 6. 帯の中の ALT / リンク / 縮小 を押した時（未確認・推測）

- ALT: 4 と同じ形で、帯が「代替テキストの入力欄 + 適用 + ×」に入れ替わる（推測）
- リンク（画像）: 4 と同じ形で URL の入力欄 + 適用 + ×（推測）
- 縮小: 押した瞬間に画像が小さくなり、アイコンが外向きの矢印（拡大）に変わる（推測）

## 7. 実装前の差（2026-09-11 の記録。モックに合わせて作り直し、同日に解消）

| 差 | 今 | note |
|---|---|---|
| 帯の中身 | リンク / ALT / 縮小 / 配置 / 出典 / 横に並べる / 削除 | リンク / ALT / 縮小 / 配置 / 削除（出典は無い。横に並べる は note に無い機能） |
| 配置 | 帯の下に 3 つの面が開く | 帯そのものが 3 つに入れ替わる |

## 8. こちらで決める物（note に無い）

- **横に並べる**（gallery）: 帯の右端、削除の左に 2 列のアイコンで置く。隣に画像がある時だけ
- **出典の attr**: 画面から新しくは付けない。値がある時だけキャプションの下に「出典: …」。押すと 4 と同じ形（帯が「出典の名前 / URL の入力 + 適用 + ×」に入れ替わる）で直せる
