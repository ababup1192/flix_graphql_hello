画像の帯モック（note の実物に合わせる）

docs/design/richtext-note-image-ui.md の表を HTML にした物。ダークで note と並べて見る。

1. 画像を選んだ時

キャプションを入力

2. 配置を押した時（帯が 3 つに入れ替わる）

キャプションを入力

3. キャプションを編集している時（画像の枠と帯は無い）

test|

4. キャプションの帯でリンクを押した時（帯が入力に入れ替わる）

test

5. リンクの掛かった文字を選んだ時（下に URL の面）

test
https://google.com/

6. ALT を押した時（推測。4 と同じ形）

キャプションを入力

7. 縮小した時（アイコンが拡大に変わる）

キャプションを入力

8. 出典の attr がある時（こちらの決め。押すと 4 の形で直せる）
