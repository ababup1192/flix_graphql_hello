## 1. 今日決めた仕様

### 進め方

実物を見る → 言語化して表にする → HTML のモックを作る → 画像で並べる → 実装 → また画像で並べる。
推測で直さない。調査で書いた「推測」は実物で覆ることが実際に 3 回あった（区切り線・引用の背景・引用の縦線）。

### HTML の形（すべて class 無し）

| 物 | 形 |
|---|---|
| 画像 | `figure > img + figcaption`。出典は `figcaption > cite > a` |
| 画像のリンク | `figure > a > img` |
| 画像の縮小と配置 | `figure[data-size="small"][data-align="left"]` |
| 並べた画像 | `figure[data-gallery="3"]` の中に `img` を並べる。画像ごとのキャプションがある物だけ内側を `figure` で包む |
| 引用 | `figure[data-quote] > blockquote + figcaption > cite` |
| リンクカード | `a[data-link-card]` の中に `span` と `img`。iframe も JavaScript も使わない |
| コード | `pre[data-file-name][data-highlight-lines][data-wrap] > code.language-xxx` |
| 数式 | `span[data-math="inline"]` と `div[data-math="block"]`。中身は TeX のまま |
| 図 | `pre[data-diagram="mermaid"]`。中身は mermaid のソース |

組版（数式）と作図（mermaid）は CMS が行わない。サイト側が好きな道具で描く。

### doc の形

**「文字とマーク」で持てる物は属性の文字列にしない。**今日この方針で 2 つ直した。

- 画像のキャプション: `attrs.caption`（文字列）→ `image` の content（inline）
- 引用の出典: `attrs.cite` / `citeUrl` → `blockquote` の最後の子 `quoteCite` の content（inline）

理由は、HTML も Markdown も既に「文字とマーク」で表しているのに doc だけが平たい属性だったこと。
そのせいで画面に「URL を入れる別の口」が要り、鎖のアイコンのような物が生まれていた。
旧形式はどちらも**読む側だけ互換**で、読み込むと新しい形に移る。

### Markdown の方言

既にある方言から広い物を選ぶ。自分で発明しない。

| 物 | 書き方 | 由来 |
|---|---|---|
| 画像の幅など | `![alt](asset:ID){width=800 size=small align=left source="…"}` | Pandoc 系 |
| 画像のキャプション | 画像の行の次の行に `*…*`（並べた時は枚数分を空白区切り） | Zenn |
| 引用の出典 | `> — [出典](URL)` | — |
| コードのファイル名 | 調査の結論は `title="foo.js"`（Docusaurus 系）。**未着手** | Docusaurus / Hugo |
| コードの強調行と折り返し | ```` ```ts:a.ts {1,3-5 wrap} ```` | Zenn + 独自 |
| フェンス | `~~~` と 4 個以上も**読める**（書き出しは常にバッククォート） | CommonMark |

### 画面の決め

- 画像を選ぶと上に帯（リンク / ALT / 縮小 / 配置 / 削除）。ALT とリンクは帯が入力に入れ替わる
- 並べた画像の列数は**選ばせない**（枚数から決まる）。解除は帯の「1 枚ずつに戻す」
- 並べた画像のキャプションは**画像ごとだけ**（全体に 1 つは持たない）
- 引用は濃い背景の箱。出典は箱の外の下、右寄せ。線も枠も無い
- 数式は普段は組版だけ。押すと TeX の欄。ホバーで右上に削除
- コードは帯が下、右にファイル名と言語。左に行番号（押して強調行を選ぶ）
- ツールバーは 9 個 + 「…」。ブロックを入れる物は「+」の一覧に寄せる
- 帯は編集できない。浮く面は親を基準に置き、画面からはみ出さない

## 2. 今日やった作業

### CMS（Flix）

- 画像と引用の出典（`source` / `sourceUrl` / `cite` / `citeUrl`）を HTML と Markdown に通す
- 画像のキャプションを内容（inline）に。引用の出典も内容（`quoteCite`）に
- 画像と並べた画像を 1 つの node に（`image > imageItem+`）。列数は持たない
- 画像のリンク・縮小・配置（`href` / `size` / `align`）
- リンクカードの OGP（`link_cards` の表、`Ogp.flix`、`fetchLinkCard` / `linkCards`、取り直しの仕事）
- コンテンツ API に `RichText.assets` と `markdown`、`blog(slug:)` の直引き
- Webhook が Next.js の開発サーバに届かない不具合を修正（HTTP/2 の切り替えヘッダ）
- Webhook の通知に `slug` を追加
- コードのフェンスの互換（`~~~` と 4 個以上）と折り返し（`wrap`）
- 既定スキーマの著者に slug

### 画面（Elm + TipTap）

- 画像の帯・キャプション・出典・リンク・縮小・配置
- 引用の箱と出典
- リンクカードと埋め込み（貼った瞬間に OGP を取る）
- 自動保存（3 秒）と「保存済み HH:MM」
- 浮くツールバーと「+」の一覧、`/` での絞り込み
- 数式（組版と TeX の切り替え、削除、矢印キー）
- コードブロック（下の帯、言語の候補、行番号、強調行、ファイル名から言語の自動補完）
- 言語を 75 → 88 に
- ツールバーを 17 → 9 + 「…」に
- メディア選択の帯を固定
- リンクの面を Elm に移す（TS の 316 行が消え、文言 16 個が見張りに乗った）
- `Ui.Stage` / `Ui.Modal` / `dangerButton` / `iconButton`
- `web/ui.ts` の部品（帯・浮く面・入力・アイコンのボタン）
- 文言の見張りを TypeScript にも拡大（日本語 140 個）
