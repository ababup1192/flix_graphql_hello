ギャラリーとキャプションの挙動（こちらの想定）

違う所を指差してください。橙色の印が付いている所は、まだ決まっていない点です。

1. 画像を 2 枚以上えらぶと、並んだ状態で入る

メディアの面で 2 枚えらぶと、こう入ります。列数は選ばせません。2 枚なら 2 列、3 枚なら 3 列、4 枚以上は 3 列で折り返します。

2. 並んだ画像ぜんたいを選んだ時（枠は外側）

帯は 2 つだけ。縮小と配置は並べている間は出しません（列の幅が決まっているので効かないため）。

3. 並んだ中の 1 枚を選んだ時（枠は内側）

帯は リンク / ALT / 削除。縮小と配置は出しません。
「ぜんたい」と「1 枚」で帯が変わります。ここが分かりにくいかもしれません。

4. キャプションは画像ごと。空の時は場所だけ空ける

触っていない時。文字は出しませんが、場所は空けます（乗せた時に本文が動かないように）。

乗せた時、または書いた時。

5. 1 枚消すと、単独の画像に戻る

2 枚目を消すと…

…1 枚の画像に戻り、帯も リンク / ALT / 縮小 / 配置 / 削除 の 5 つに戻ります。

6. 逆向き。1 枚の画像に画像を足すと並ぶ

ここが未定です。1 枚の画像の隣に画像を足す道が今ありません。
案 A: 画像を選んだ帯に「画像を足す」を置く。案 B: 2 枚目を貼ると自動で隣に並ぶ。案 C: 並べ直しは「1 枚ずつに戻す」→ メディアから選び直す。
